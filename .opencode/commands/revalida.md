---
description: Open Revalida's web workflow for a business decision
---

The Revalida council runs in the web app, not in this OpenCode session. Do not start a council or answer the decision as the board here. Send the user to http://localhost:4730; if needed, start the app with `npm start` from the project directory.

The web flow will clarify the decision, show the proposed brief and advisor board, and wait for the founder to select **Confirm and start council** before any rounds run.
